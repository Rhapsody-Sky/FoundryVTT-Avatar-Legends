# Avatar Legends RPG

Play [Avatar Legends RPG](https://magpiegames.com/pages/avatarrpg) in **Foundry VTT 14**, with character sheets, dice rolls and tools for your campaign.

This project continues [Paul Cosgrove / demondownload's original Legends system](https://gitlab.com/pacosgrove1/legends). Thank you to Paul and everyone who contributed to it. I maintain this continuation independently; it is not affiliated with Magpie Games or the Avatar rights holders.

## Features

- Player and NPC character sheets
- Campaign worksheet
- Dice rolls and support for Dice So Nice!
- Optional Exchange tracker
- Compendiums of publicly available playbooks and reference material

## Installation

> Version 2.2.0 and the migration module are being tested. The published release still uses the old system ID; the instructions below apply to the upcoming release.

In Foundry's Setup screen, open **Game Systems → Install System**, paste this URL into **Manifest URL**, and click **Install**:

```text
https://github.com/Rhapsody-Sky/FoundryVTT-Avatar-Legends/releases/latest/download/system.json
```

**Already using the original system?** Follow the short [switching guide](docs/switching.md) / [Umstiegsanleitung](docs/umstieg.md). Back up your world before switching.

The new system uses its own ID, `avatar-legends`. After switching, use Foundry's normal **Update** button under **Game Systems**; no update lock or manual ZIP replacement is needed.
