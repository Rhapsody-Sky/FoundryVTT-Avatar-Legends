# Changelog

## 2.2.1

- Supports Foundry VTT 14 with character sheets, campaign tools and the optional Exchange Tracker.
- Uses the system ID `avatar-legends` for installation and updates through Foundry.
- Checks playbook attachments before changing character data. Chat rolls use the character’s move and identify the character who rolled.
- Handles cancelled stance rolls and counts a total of zero as a miss.
- Avatar Legends Migration 1.0.1 moves existing `legends` worlds and preserves compendium access, referenced artwork and legacy links. See the [switching guide](docs/switching.md).

For earlier changes, see the [original Legends project](https://gitlab.com/pacosgrove1/legends).
