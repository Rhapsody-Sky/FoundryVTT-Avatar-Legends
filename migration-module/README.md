# Avatar Legends Migration

Moves an existing `legends` world to Avatar Legends RPG (`avatar-legends`) on Foundry VTT 14. The assistant guides the GM through the switch and preserves world data, old compendiums and references to them.

Back up the world and old system, then follow the [switching guide](https://github.com/Rhapsody-Sky/FoundryVTT-Avatar-Legends/blob/main/docs/switching.md) or [deutsche Umstiegsanleitung](https://github.com/Rhapsody-Sky/FoundryVTT-Avatar-Legends/blob/main/docs/umstieg.md).
